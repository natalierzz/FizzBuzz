
# FizzBuzz

## Descrição
Projeto desenvolvido em linguagem C para
praticar estruturas de repetição e condicionais,
utilizando o GitHub como repositório remoto.

## Funcionamento
O programa recebe um número inteiro N e
percorre os números de 1 até N.

Para cada número:
- Se for múltiplo de 3 e 5, imprime FizzBuzz.
- Se for múltiplo de 3, imprime Fizz.
- Se for múltiplo de 5, imprime Buzz.
- Caso contrário, imprime o próprio número.

## Exemplo de execução

Entrada: 15

Saída:
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
